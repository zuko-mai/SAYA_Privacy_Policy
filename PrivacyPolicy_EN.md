## 2. Data we process

Depending on features you use, we may process:

### Account & identity
- user ID (Firebase Auth UID);
- email (if provided via Google / Apple Sign In);
- display name;
- Sign-In provider data as supplied by Google or Apple.

### Profile & pregnancy-related data (may be health-related)
- date of birth / age (if provided);
- city; goals;
- pregnancy parameters (e.g. due date, conception / LMP, cycle length);
- pre-pregnancy height/weight (if provided);
- baby profile, avatar, activity trackers (contractions, kicks, medication, diapers, etc.);
- packing lists, birth plan items, and similar user-created content;
- pinned activity order and profile settings.

### Partner features
- invite / pairing codes;
- data you choose to share with a linked partner.

### AI assistant
- prompts and responses;
- context needed to answer (e.g. pregnancy week / profile fields if used by the feature);
- usage quota information.

### Subscriptions
- Premium entitlement / purchase identifiers;
- payments handled by **Apple App Store** and/or **Google Play** (we do not store full card numbers);
- **RevenueCat** may process subscription/transaction identifiers.

### Device & notifications
- push tokens (Firebase Cloud Messaging);
- notification preferences;
- technical device/app data (OS, app version, language, timezone, connectivity as needed);
- on-device local storage (e.g. preferences, local reminders).

### Media
- uploads you make if a feature supports them (Firebase Storage);
- on-device media cache.
